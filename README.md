# APEX Role-Based Access Management System

## Overview

APEX is a role-based access management application built using Angular, Node.js, Express, and MongoDB Atlas.

The application provides authentication, role-based authorization, user administration, and device record management through a responsive web interface.

## Features

### Authentication
- Login system
- Role-based access control
- Admin and General User roles

### Dashboard
- User profile card
- Role-based record visibility
- Search functionality
- Device records dashboard


### Admin Panel
- Add users
- Edit users
- Delete users
- View all registered users
- User status indicators

### Backend
- REST APIs
- MongoDB Atlas integration
- Async API response simulation
- User CRUD operations

## Tech Stack

- Angular
- TypeScript
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
